# Vendored test vectors

This directory contains the files used by `@noble/ed25519` from
[`paulmillr/acvp-vectors`](https://github.com/paulmillr/acvp-vectors), vendored
at commit `56669e07d50cd6b0c19d81a63be2e987dd5beeee` (2026-08-24).

Only Ed25519-relevant ACVP projections, the RFC 8032 and Wycheproof Ed25519
vectors, the JSON gzip helper, its type declaration, and the upstream license
are included.
